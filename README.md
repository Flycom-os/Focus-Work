# Focus Work

Pet‑project: **Frontend (React/Vite)** + **Backend (NestJS/Prisma/Postgres)**.

## Что внутри

- **Tracker**: issues + timesheets + профиль (YouTrack‑like прототип)
- **CRM**: настройки системы, склады, компании, профиль
- **Miro**: whiteboard (доски/ноды)
- **Storybook**: библиотека UI компонентов + unit‑тесты

## Быстрый старт

### Backend

```bash
cd backend
npm i
npm run start:dev
```

### Frontend

```bash
cd frontend
npm i
npm run dev
```

## Документация (Wiki)

Открой страницу `\`/wiki\`` в приложении — там собрана подробная документация по модулям, API и типичным проблемам.
