# Frontend (Focus Work)

## Стек

- React 19 + React Router
- Vite 8
- Storybook
- Vitest + Testing Library

## Запуск

```bash
npm i
npm run dev
```

По умолчанию фронт стартует на `:3000`.

## Storybook

```bash
npm run storybook
```

Сборка:

```bash
npm run build-storybook
```

## Тесты

```bash
npm test
```

UI режим:

```bash
npm run test:ui
```

## Страницы

- `/tracker` — трекер (issues/timesheets/profile)
- `/crm` — CRM настройки
- `/miro` — Miro доски
- `/wiki` — документация по системе
