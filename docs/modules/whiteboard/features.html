🛠 Фичи и Практические гайды Whiteboard

В этом документе содержатся детальные инструкции по оптимизации производительности холста, добавлению новых графических инструментов и экспорту доски.

📌 1. Детальный разбор ключевых возможностей

Холст Whiteboard спроектирован как высокопроизводительное графическое приложение. Ниже описан функционал, с которым вы будете взаимодействовать:

📝 Интерактивные стикеры (Sticky Notes)

Аналог физических стикеров Miro. Стикеры рендерятся через SVG-элемент <foreignObject>, что позволяет встраивать внутрь SVG стандартный HTML-текст (textarea), с поддержкой переноса строк, шрифтов и выделения курсором.

🏹 Умные стрелки-соединители (Arrows)

Соединяют две фигуры. При перетаскивании фигуры стрелка автоматически пересчитывает свои координаты начала и конца. Для расчета мы используем алгоритм пересечения луча с границами ограничивающего прямоугольника фигуры (Bounding Box).

✏️ Сглаживание произвольного рисования

При рисовании карандашом (режим PATH) сырые координаты мыши содержат много угловатых отрезков. Мы сглаживаем их с помощью формулы квадратичных кривых Безье, преобразуя набор точек в сглаженную строку SVG-команд вида d="M x y Q x1 y1 x2 y2".

💾 Экспорт в PNG и SVG

Для экспорта мы сериализуем текущее дерево SVG в строку XML, конвертируем ее в URL base64 и рендерим на скрытом Canvas элементе. Далее с помощью метода canvas.toDataURL("image/png") скачиваем файл на ПК пользователя.

⚡ 2. Руководство по оптимизации производительности

🚀 Проблема: Браузер зависает при рендеринге 10 000+ элементов

Поскольку мы используем SVG, каждая фигура становится частью дерева DOM. При попытке перетащить холст с 10 000 фигур, браузер вынужден пересчитывать стили и макет (Reflow/Repaint) для 10 000 DOM-узлов 60 раз в секунду. Это приводит к падению частоты кадров до 5-10 FPS.

Как исправить это в будущем (Архитектурный план перехода на Canvas):

  • Переход с SVG на HTML5 Canvas API: Рисование происходит напрямую в буфер пикселей (видеокарту), минуя создание DOM-узлов. Отрисовка 10 000 прямоугольников на Canvas занимает менее 2 миллисекунд.
  • Фрустум-куллинг (Viewport Clipping): Мы отрисовываем только те фигуры, координаты которых попадают в текущий прямоугольник видимости экрана. Фигуры за пределами экрана игнорируются при рендеринге.
  • Пространственное индексирование (Quadtree): Для быстрого поиска фигур, пересекающих экран, мы делим плоскость на квадранты. Поиск фигур для рендеринга занимает O(log N) времени вместо O(N).

🛠 3. Практические руководства (How-To)

🎨 Гайд: Как добавить новый инструмент — Рисование кругов (Circle Tool)?

Давайте пошагово разберем, как расширить возможности панели инструментов и холста, добавив инструмент создания окружностей.

Шаг 1: Обновление типов

Добавьте значение CIRCLE в тип ShapeType в вашей Prisma-схеме и запустите миграцию базы данных. Также обновите стейт инструментов в Canvas.tsx:

// Добавляем CIRCLE в список доступных инструментов
const [tool, setTool] = useState<"SELECT" | "RECTANGLE" | "CIRCLE" | "PAN">("SELECT");

Шаг 2: Добавление кнопки на панель инструментов

<button 
  onClick={() => setTool("CIRCLE")} 
  class={`px-3 py-1.5 rounded text-xs ${tool === "CIRCLE" ? "bg-indigo-600 text-white" : "hover:bg-slate-100 dark:hover:bg-slate-800"}`}
>
  + Окружность
</button>

Шаг 3: Логика обработки мыши

Обновите метод handleMouseDown, чтобы при клике создавалась фигура с типом CIRCLE:

if (tool === "CIRCLE") {
  const { x, y } = getCanvasCoords(e.clientX, e.clientY);
  const newCircle: Shape = {
    id: crypto.randomUUID(),
    type: "CIRCLE",
    x,
    y,
    width: 80,  // Для круга width и height — это диаметр
    height: 80,
    fill: "#fbcfe8" // Нежно-розовый
  };
  setShapes(prev => [...prev, newCircle]);
  emitShapeUpdate(newCircle);
  setTool("SELECT");
}

Шаг 4: Рендеринг круга в SVG

Внутри контейнера рендеринга добавьте условие для отрисовки тега <circle>:

{shapes.map(shape => {
  if (shape.type === "CIRCLE") {
    // В SVG circle центрируется по cx/cy, а радиус r — половина ширины
    return (
      <circle
        key={shape.id}
        cx={shape.x + shape.width / 2}
        cy={shape.y + shape.height / 2}
        r={shape.width / 2}
        fill={shape.fill}
        stroke="#db2777"
        stroke-width="2"
      />
    );
  }
  
  // Рендеринг прямоугольника...
})}

❓ 4. FAQ: Ошибки позиционирования на Retina экранах

Причина: Экраны высокой плотности пикселей (High-DPI / Retina) используют коэффициент масштабирования window.devicePixelRatio = 2 или выше.

Если вы рендерите холст через HTML5 Canvas и не масштабируете внутреннее разрешение холста, картинка будет размытой, а координаты мыши разъедутся.

Решение: В SVG этой проблемы нет, так как SVG адаптивен изначально. Но если вы дорабатываете Canvas-версию, не забывайте масштабировать размеры холста:

const dpr = window.devicePixelRatio || 1;
canvas.width = rect.width * dpr;
canvas.height = rect.height * dpr;
ctx.scale(dpr, dpr); // Важно: масштабируем контекст рисования!
