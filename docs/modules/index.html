🏁 Инструкция по быстрому старту (Onboarding)

Пройдите эти шаги, чтобы развернуть Focus-Work локально на вашей машине менее чем за 10 минут:

1

Клонирование репозитория и установка зависимостей

Стяните последнюю версию `main` ветки и установите пакеты:

git clone https://github.com/flycom-os/focus-work.git
cd focus-work
npm install
2

Настройка окружения (.env)

Скопируйте пример настроек и заполните переменные окружения:

DATABASE_URL="postgresql://postgres:postgres@localhost:5432/focus_work?schema=public"
NEXTAUTH_SECRET="your-super-secret-key-for-nextauth"
NEXT_PUBLIC_WS_SERVER_URL="http://localhost:3001"
RTSP_STREAM_URL="rtsp://admin:password@192.168.1.100:554/live"
3

Подъем базы данных в Docker

Если у вас не установлен PostgreSQL локально, запустите контейнер:

version: '3.8'
services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: focus_work
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data

volumes:
  pgdata:
docker-compose up -d
4

Миграции Prisma и Заполнение БД (Seeding)

Накатите схему БД и заполните ее тестовыми данными:

npx prisma migrate dev --name init
npx prisma db seed
5

Запуск в Dev-режиме

Запустите параллельно веб-сервер Next.js и WebSocket-сервер:

npm run dev
💡 Приложение запустится на http://localhost:3000. WebSocket-сервер для Whiteboard поднимется на порту 3001. Логин по умолчанию: admin@focus.work / admin123.

❓ Общие вопросы по онбордингу

Мы крайне не рекомендуем делать это, так как SQLite не поддерживает некоторые JSON-функции PostgreSQL, которые используются в Модуле Whiteboard для сериализации фигур и логов. Также SQLite не поддерживает параллельные транзакции на запись, что заблокирует CRM.

Если вам обязательно нужна легкая база, используйте Docker-контейнер PostgreSQL, как описано в шаге 3 руководства быстрого старта.

Убедитесь, что запущен WebSocket бэкенд. При запуске через npm run dev скрипт параллельно поднимает Next.js (на порту 3000) и WebSocket-сервер из папки backend/src/server.ts (на порту 3001).

Если вы запускаете их по отдельности, перейдите в папку бэкенда и запустите его вручную: npm run dev:websocket.
